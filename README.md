# Tawfiq Seller

Личный кабинет продавца Tawfiq. Это рабочий интерфейс магазина автозапчастей, шин и дисков: заказы, товары, возвраты, продвижение, аналитика, финансы, отзывы, сотрудники и Tawfiq AI.

Демо-магазин: **AUTO PARTS PRO**. Второй магазин: **SHINA LINE**. Валюта — сум.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Страница входа: [http://localhost:3000/login](http://localhost:3000/login). Любые данные пускают в кабинет.

## Что уже работает

- Навигация, вкладки, фильтры, поиск, период, графики, таблицы и пагинация
- Карточка заказа и следующий статус
- Товары: выбор, скидка, снятие с продажи, короткая карточка и пример «Улучшить фото»
- Скачивание финансового CSV за выбранные даты
- Ответы на отзывы, в том числе черновик Tawfiq AI
- Команда сотрудников и права ролей
- Чат Tawfiq AI: быстрые команды, черновик товара, скидка и отчёт — опасные шаги только после подтверждения
- Русский интерфейс, переключение на узбекский и английский в настройках

Данные демонстрационные и живут в браузере до обновления страницы.
